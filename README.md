## Project overview

GreenLoop Campus Pantry is a fictional, student-run campus organisation. It aims to help students access affordable food while reducing unnecessary food waste. The pantry collects suitable surplus food from local shops, cafés, and campus events, then shares it with students for free or at a low price.

This website is an educational prototype. It provides information about the pantry, food categories, volunteering, and ways to make contact.

## Website goals

- Explain GreenLoop’s purpose, mission, and vision.
- Show examples of food categories that may be available.
- Encourage students to volunteer.
- Let students and potential food donors find enquiry information.
- Provide clear navigation on desktop and mobile screens.

Possible future measures of success include visits to the Home and About pages, completed enquiries, volunteer-interest submissions, and clicks on the Pantry and Volunteer links. The prototype does not collect analytics or form submissions.

## Project files

- `style.css` — Shared page styling and mobile layout.
- `script.js` — Displays a confirmation for the demo forms. It does not send or save form information.

## Technologies

- HTML5 for the page content and forms.
- CSS3 for layout, colours, and responsive styling.
- JavaScript for the demo form confirmation.

The current project does not use TypeScript, a database, a package manager, or external libraries. No installation is required.

## How to view the website

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit the other pages.

## Testing checklist

- Open each page and check the main navigation links.
- Resize the browser to check the mobile layout.
- Check that form fields have labels and required fields are enforced.
- Submit a demo form and confirm that its notice appears.
- Confirm that the forms do not send or store personal information.

## Limitations

- GreenLoop is fictional. The address, opening hours, telephone number, and social media link shown on the Contact page are examples or placeholders and must be replaced before any real-world use.
- Pantry categories are examples, not a live inventory. Actual food availability would change regularly.
- Forms only display a local confirmation; they do not deliver messages or store data.
- The site has no user accounts, food database, live stock updates, volunteer calendar, payment feature, or analytics.
